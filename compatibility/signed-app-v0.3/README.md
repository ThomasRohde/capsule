# Signed application v0.3 compatibility vectors

These fixtures define the independent Python and Rust compatibility baseline for
`org.sqlite-capsule.signed-app/0.3`. They use only public development test keys
and confer no publisher trust.

The SQL includes the deterministic Ed25519 envelope recorded in `vectors.json`.
Rust verifies that envelope cryptographically and under the v2 context; the
independent Python implementation reproduces the exact canonical bytes/digest
and exhaustively mutates signed and excluded row classes. The old envelope must
remain valid for excluded mutations and become digest-mismatched for every
signed-compartment mutation.

The v0.2 vector directory remains normative and is not regenerated by M01.
