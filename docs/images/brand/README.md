# SQLite Capsule brand marks

These are the canonical SVG source variants for documentation and interfaces:

- `sqlite-capsule-mark.svg`: fixed-colour plain mark.
- `sqlite-capsule-mark-currentcolor.svg`: plain mark with a negative-space play
  triangle; the capsule uses `currentColor` and has a standalone blue default.
- `sqlite-capsule-mark-verified.svg`: fixed-colour mark with the verification
  badge.
- `sqlite-capsule-mark-verified-currentcolor.svg`: verified mark whose capsule
  uses `currentColor` and whose play triangle is negative space.

The Tauri platform resources under `native/desktop/src-tauri/icons/` are
generated application assets rather than the canonical documentation sources.
